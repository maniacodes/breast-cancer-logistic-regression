# Breast Cancer Classification with Logistic Regression

## Project Overview

In this project, I built a Logistic Regression model using the Breast Cancer dataset from Scikit-learn.

The goal is to classify tumors into two classes based on their features.

## Algorithm

- Logistic Regression

## Preprocessing

- Train/Test Split
- StandardScaler

## Evaluation

The model was evaluated using:

- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-Score
- Classification Report

## Result

Accuracy: 97.37%
